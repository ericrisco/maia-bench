    Preguntes i respostes

    Com avaluo el meu model?

    Clona el repositori i executa python3 tools/executa.py --model ollama:el-teu-model. Funciona amb Ollama, Ollama Cloud, OpenAI, Anthropic, OpenRouter i Vertex. Després, python3 tools/puntua.py resultats/<nom> i python3 tools/web.py.

    Què veu el model?

    Només la pregunta, i les quatre opcions si és un test. Mai el context ni la resposta de referència. Mateix prompt i temperatura 0 per a tothom.

    Qui puntua les respostes obertes?

    Un jutge fixat, __JUTGE__, amb la resposta de referència, els fets clau i una llista d'errors a penalitzar. Una resposta amb un d'aquests errors no pot treure la nota màxima.

    El jutge és imparcial?

    No del tot: un jutge només detecta els errors que coneix. Per això cada pregunta porta errors típics. Quan el model avaluat és el mateix jutge, la taula ho marca.

    Què és una pregunta trampa?

    Una pregunta que dona per bo un fet fals. Puntua el model que el rebutja i diu què és cert; el que s'inventa una explicació treu un zero.

    Què són les preguntes no vistes?

    Preguntes sobre __N_FITXES__ fitxes reservades que mai entren a l'entrenament de maia. Mesuren si un model s'inventa el que no sap.

    Per què hi ha un interval?

    Perquè les preguntes són una mostra. L'interval surt de remostrejar-les mil vegades. Dues notes amb intervals que se solapen no es poden ordenar.

    Per què ara només compten els tests?

    Les obertes i les trampes les puntua el jutge, i aquesta passada encara no s'ha fet. Quan es faci, la nota inclourà les 926 preguntes.

    maia juga amb avantatge?

    maia és el model del projecte que ha fet el benchmark. Per això el mètode, les preguntes i el codi són públics, i la taula el marca.

    Mesura també com parla?

    Encara no. La part de llengua (perplexitat sobre parla real, test dialectal i prova cega amb andorrans) està en construcció.
